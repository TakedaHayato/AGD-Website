# 🛡️ AEGIS GLOBAL DEFENSE | OPERATIONS CENTER

![AGD Logo](assets/AGDlogo.gif)

Willkommen im offiziellen **Strategic Command Interface** der Aegis Global Defense Community. Diese Webseite dient als zentraler Uplink für Einsatzparameter, Wetter-Radar und Truppen-Kommunikation.

---

## ⚡ Key Features

* **🛰️ Real-Time Intelligence:** Integriertes Wetter-Radar mit automatischer Standorterkennung (Standard: Bayern).
* **🌓 Adaptive Interface:** Vollständiger Dark- und Light-Mode Support für operative Flexibilität bei Tag und Nacht.
* **🌍 Multi-Language Uplink:** Nahtloser Wechsel zwischen Deutsch und Englisch für internationale Einsätze.
* **💬 Tactical Feed:** Live-Anbindung an den Discord-Kommandokanal.
* **📱 Mobile Optimized:** Vollständig responsives Design für den Zugriff via Feld-Terminals (Smartphones).
